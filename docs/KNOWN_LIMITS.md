# Known limits

- Research validity is not established by software tests.
- Live endpoint behavior and compatibility remain unverified in this public snapshot and depend on current external APIs, account permissions, rate limits, and human authentication.
- Thresholds in the example configuration are policy inputs, not universal statistical facts.
- SQLite and the synchronous worker target one local operator, not a distributed service.
- LLM diagnoses can be wrong; deterministic validation and bounded retries reduce, but do not remove, that risk.
- The public snapshot excludes private pilot data, so it cannot independently reproduce the private pilot's platform results.
- There is no dashboard and no automatic submission in the public workflow; candidate submission remains a human decision.
